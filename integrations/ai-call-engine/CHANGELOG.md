# Changelog

## [1.0.0] — 2026-11-26

### Added
- Initial release of AI Call Engine
- Automatic outbound AI calling on request closure events
- Vapi voice provider adapter with Indian calling support
- Mock provider for local development and demonstration
- Event-driven architecture with background queue processing
- Duplicate call prevention with idempotency keys
- Configurable AI conversation engine with multilingual support (English, Hindi, Tamil)
- Call status state machine with validated transitions
- RESTful API for call management and event processing
- Webhook handler for voice provider callbacks
- React AICall component for manual testing and integration
- Bearer token authentication for API security
- Rate limiting and CORS configuration
- Webhook signature verification
- SQLite database for event and call storage
- Comprehensive test suite
- Docker support
- Complete documentation
